THE SECRET LOVE BOX 💜
A cute romantic puzzle game built with HTML, CSS, and JavaScript.

HOW TO PLAY
1. Extract SecretLoveBox_Game.zip.
2. Open the extracted SecretLoveBox_Game folder in Visual Studio Code.
3. Open index.html in your browser, or install the Live Server extension and click "Go Live".
4. Solve the three puzzles, use the clues if needed, and unlock the surprise love letter.

FILES
- index.html — game screens and love letter
- style.css — lavender/pink theme, responsive layout, and animations
- script.js — puzzles, clue buttons, progress, and letter interaction

PERSONALIZE THE LETTER
Open index.html and find the element with id="letter-body". Replace its text with your own message.
You can change "To My Love" and "Always yours" in the same file.

PERSONALIZE THE PUZZLES
Open script.js and edit the puzzles array. Each puzzle includes its prompt, hint, and correct answer.

NOTES
- No build tools or installation are required.
- Google Fonts are imported for decorative typography; the game still works offline with fallback fonts.
- To publish online, upload index.html, style.css, and script.js to a GitHub repository and enable GitHub Pages. Upload the extracted files, not just the ZIP.
